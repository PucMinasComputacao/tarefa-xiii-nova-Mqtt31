Sobre o Projeto

RealMusic.Online é um projeto acadêmico da disciplina de Desenvolvimento Web – PUC Minas 2026/1. O site apresenta gêneros musicais com seus respectivos clássicos, carregando todo o conteúdo dinamicamente a partir de uma estrutura JSON via JavaScript puro.
